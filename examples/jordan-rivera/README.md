# Example: Jordan Rivera

A finished profile for an invented person. Everything here is made up except the university and certification names, and proof files are described, not included.

Show it at the start as "where we're headed". After each intake phase, compare the user's file with the matching one here, and ask one more round or log the gap in PROGRESS.md if theirs is thinner. Never copy a fact, number or wording into their files.

| File | What makes it complete |
|---|---|
| PROFILE.md | Each job with HR title, dates, scope, tools, sources. Education. Held certs only |
| TARGETS.md | Titles wanted and refused, places, remote rules, never-send list |
| SCREEN.md | Floors, deal breakers, approved form answers, dated market bands |
| VOICE.md | Banned list, the user's own dislikes, allowed words |
| NUMBERS.md | Each figure with meaning, status (measured / estimated / identified), source, lock date |
| STORIES.md | Each story's part, result, proof, helpers, resume decision |
| DECISIONS.md | Dated one-liners with a revisit condition |
| PIPELINE.md | Every application and contact, with next step and status |
| PROGRESS.md | Each stage with its date, open questions, known gaps |
| AUTHORIZATIONS.md | The standing email permission and each application's approvals |
| RESUME-RULES.md | Width band, bullet counts, title layers, file paths |
| resume.md | The resume source text. Every line traces to STORIES and NUMBERS |
| Jordan_Rivera_Resume.docx / .pdf | Built from resume.md by tools/build_resume.py. Quality gate passed |
| preview/page-1.png | The page image the AI looked at in the visual check |
| scanner-config.json | Keywords, places, floors, excludes tuned to the person |
| sample-digest.txt | One morning's email |
| sample-screen.md | A pasted posting and its verdict |
| applications/ | A filled application handoff |
